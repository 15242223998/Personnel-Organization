# 辽宁工业大学 · 高校干部人事组织管理系统

面向**辽宁工业大学**组织人事工作的高校干部人事组织管理系统，依据学校“**十四五**”规划提出的治理体系和治理能力现代化建设要求，以干部人事档案数据为底座，服务高素质专业化干部队伍建设。

系统涵盖干部信息管理、组织机构、选拔任免、职级晋升、调配管理、年度考核、民主测评与平板评审投票（含签字留证）、监督管理、日常事务、统计分析等核心模块，覆盖“选、育、管、用”全链条，采用政务蓝风格界面，与学校智慧校园建设整体规划相衔接。

## 建设背景

- 紧扣**辽宁工业大学“十四五”规划**中关于深化内部治理、推进管理数字化转型的目标，把组织人事工作纳入学校智慧校园“一张网、一平台、一门户”建设框架。
- 面向“十四五”干部队伍建设需要，落实党管干部原则，实现干部档案电子化、任免流程规范化、考核监督全程留痕，为学校党委科学选人用人提供数据支撑。
- 以“数据一个库、业务一条链、审批一个口”为建设方向，逐步实现组织机构、干部档案、任免调配、考核监督等业务协同联动。

## 功能模块

### 干部管理
- **干部信息管理** — 干部档案的增删改查、批量导入导出、排序筛选、在职/离退休/调出/辞职分库
- **后备干部库** — 后备干部入库（仅限在职干部）、培养跟踪、出库管理

### 组织机构
- **组织机构管理** — 机构树形管理、编制数/实有人数维护
- **职务层次管理** — 职务层次的增删改查
- **职级管理** — 职级类型的统一管理

### 干部业务
- **干部任免管理** — 全流程管理（动议 → 民主推荐 → 考察 → 讨论决定 → 公示 → 任职），任职备案自动回写干部档案现任信息
- **干部调配管理** — 干部调动/转任记录管理，自动同步档案状态（在职/离退/调出）
- **职级晋升管理** — 职级晋升记录管理，自动同步干部职级

### 监督考核
- **干部考核管理** — 年度考核（优秀/称职等次，自动回写档案考核记录）、考核方案、德能勤绩廉维度/指标模板、民主测评
- **平板评审投票** — 面向局域网平板现场评审：评分式（按指标打分）与表决式（赞成/反对/弃权）两种投票、评审材料审阅、手写签字留证（签字图像+MD5+设备IP+时间留痕）、票决结果与签字记录查询；平板端访问 `/tablet`
- **干部监督管理** — 廉政意见、信访举报、个人事项报告、预警记录

### 日常事务
- 证照管理、出境记录、休假管理、教育培训、挂职锻炼（均含业务规范校验与台账）
- 干部自助申报 — 用户（`sys_user`）与干部档案（`cadre_info`）绑定后，可提交信息修改/请假/培训/出国(境)等申报并按归属档案归档

### 统计分析
- 年龄/性别/学历/政治面貌/职务层次图表分析（ECharts）
- 机构干部统计表

### 系统管理
- 用户管理、角色管理、字典管理（国标）、操作日志/登录日志、数据权限

## 认证与安全（已启用）

- 登录成功签发 JWT（HS256，默认有效期 24 小时），前端 `Authorization: Bearer <token>` 携带
- Spring Security 统一鉴权：登录/注册/接口文档外，其余接口须携带有效令牌，未登录返回 401、越权返回 403（JSON）
- 角色权限：用户经 `sys_role` 映射为 `ROLE_XXX` 权限，可按需加 `@PreAuthorize` 细化接口权限
- 数据权限：干部档案分页/详情/导出按当前用户角色的 `data_scope`（1全部 / 3本级及下级 / 4本级）自动过滤，admin 角色不受限
- 干部状态、调配/任免/晋升均与干部档案联动，保证档案“现任职务/部门/职级/状态”一致

> 初始账号：`admin / 123456`（系统管理员，data_scope=1 全量数据）

## 快速开始

### 环境要求
- JDK 17+
- Maven 3.8+（若未安装，项目内置便携版于 `.tools-maven`，启动脚本会自动探测）
- Node.js 18+
- MySQL 8.0+
- Redis 7.0+（可选，当前代码未实际使用）

### 一键启动（推荐）

Windows 下直接双击项目根目录的 `启动系统.bat`：
1. 自动探测 JDK 17 与 Maven
2. 启动后端（`mvn spring-boot:run`，端口 8080）
3. 启动前端（`npm run dev`，端口 5173）
4. 自动打开浏览器 http://localhost:5173

也可以分别双击 `personnel-backend/启动后端.cmd` 或手动运行：

```bash
# 1. 初始化数据库（先按需修改 application.yml 中数据源）
#    默认：jdbc:mysql://localhost:3306/POP，root / 666666
mysql -uroot -p666666 < sql/init.sql

# 1.1 可选：灌入演示数据（机构/编制/干部档案 + 考核/日常事务/平板评审示例）
mysql -uroot -p666666 POP < sql/seed-demo.sql

# 2. 后端
cd personnel-backend
mvn spring-boot:run        # http://localhost:8080，API文档 /doc.html

# 3. 前端
cd personnel-frontend
npm install
npm run dev                # http://localhost:5173（已代理 /api 到 8080）
```

> 演示账号（`seed-demo.sql` 提供，密码均 `123456`）：
> - `admin`：系统管理员（全量数据）
> - `caohaoran`：组织部部长（已绑定干部档案）
> - `qinxia`：普通干部（已绑定干部档案，可在平板自助申报/参与投票）

### 构建部署

```bash
cd personnel-frontend
npm run build
```

构建产物在 `dist/` 目录，可直接部署到 Nginx 等 Web 服务器。

#### 局域网平板评审部署（Nginx 示例）

项目提供 `deploy/nginx-lan.conf`，将前端 `dist` 与后端 `/api` 同源反代后即可供局域网平板访问：

```bash
# 前端已构建出 dist 后
# 1) 按实际路径修改 deploy/nginx-lan.conf 中的 root 指向 dist
# 2) 后端运行在 127.0.0.1:8080（已由 nginx 反代 /api）
# 3) 启动 nginx（Windows 双击/命令；Linux: nginx -c .../nginx-lan.conf）
```

- 桌面后台：`http://<主机局域网IP>/`
- 平板投票页：`http://<主机局域网IP>/tablet`
- 若仅临时体验，前端可用 `npm run dev -- --host`，平板访问 `http://<主机IP>:5173/tablet`（注意放行防火墙）

## 界面预览

系统采用蓝色政务风格设计，统一的顶部渐变导航栏、左侧菜单栏和标签页布局，所有业务页面保持一致的视觉风格；登录页与首页均采用辽宁工业大学品牌标识与称谓，符合学校信息化建设的统一视觉规范。

## 说明与已知事项

- 已接入真实接口/数据的页面：登录认证、系统日志、注册审批、统计分析；**干部管理主链路（在册库/后备库/档案）、组织任免与调配晋升、干部考核管理（年度考核 + 民主测评 + 平板评审投票 + 签字留证）、日常事务（证照/出境/休假/培训/挂职/自助申报）、用户管理（含用户↔干部档案绑定）** 均已对接后端 `/api/**` 接口；个别基础配置页（如字典/角色管理）仍以演示数据展示，可沿用同一套分页/保存接口继续接入。
- 演示数据：执行 `sql/seed-demo.sql` 可重复灌入机构（27 个）、编制与干部档案（约 470 人），以及年度考核、测评方案（评分式/表决式）、证照/出境/休假/培训/挂职/自助申报等示例记录。数据中姓名随机虚构、职务为通用占位，不含真实人员信息，便于演示与联调。
- 平板评审投票：进行中方案会出现在 `/tablet` 平板端；投票完成后需手写签字留证（图像与 MD5/设备 IP 存档于 `assessment_signature`），签字后不可再改票；管理端可在方案行"更多 → 签字留证 / 测评对象与材料"中查看留证与维护评审材料。
- 干部自助申报归属：`sys_user.cadre_id` 绑定后，申报方可归属到具体干部档案；绑定操作在"系统管理 → 用户管理 → 绑定档案"。
- 干部档案等数据会按"数据权限"过滤；以 `admin/123456` 登录可查看全量数据。
- `.tools-maven/` 为 Maven 便携版（启动脚本依赖，正式安装 Maven 后可删除）。
